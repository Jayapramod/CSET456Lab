# Flask Repository Data Mining

## Overview

This project performs data mining and profiling on the open-source **Flask** software repository.

The objective is to treat a software repository as a source of structured and unstructured software engineering data. The project programmatically accesses the repository, analyzes its files and source code, and mines Git history to extract repository-level, file-level, and development-related information.

The selected repository for this lab is:

**Flask:** https://github.com/pallets/flask

---

## Objectives

The project focuses on the following tasks:

* Clone/access an open-source GitHub repository programmatically.
* Traverse repository files and identify source-code files.
* Extract repository-level and file-level metrics.
* Analyze programming languages and file types.
* Calculate Lines of Code (LOC).
* Identify the largest source files.
* Mine Git history.
* Determine the number of commits and contributors.
* Identify the most active contributors.
* Identify frequently changed files.
* Analyze commits per month.
* Calculate average files changed per month.
* Calculate file additions and deletions.
* Produce machine-readable datasets for further analysis.

## Repository Inventory

The repository inventory analyzes the Flask repository and extracts:

* Repository name
* Total number of files
* Number of source-code files
* Programming languages
* Number of directories
* Total Lines of Code
* Average LOC per source file
* Largest source files
* File-type distribution

---

## File-Level Dataset

The file-level dataset is stored in:

```text
output/file_dataset.csv
```

It contains the following fields:

| Field        | Description                 |
| ------------ | --------------------------- |
| `file_path`  | Path of the source file     |
| `language`   | Programming language        |
| `extension`  | File extension              |
| `loc`        | Number of lines in the file |
| `size_bytes` | File size in bytes          |

Example:

```text
file_path,language,extension,loc,size_bytes
src/flask/app.py,Python,.py,...
src/flask/blueprints.py,Python,.py,...
```

---

## Git History Mining

Git history is analyzed using **PyDriller**.

The analysis extracts:

* Total number of commits
* Number of contributors
* Most active contributors
* Frequently changed files
* Commits per month
* Average files changed per month
* File additions
* File deletions

The commit-level dataset is stored in:

```text
output/commit_history.csv
```

---

## Generated Datasets

### `file_dataset.csv`

Contains file-level source-code metrics.

### `commit_history.csv`

Contains information about individual commits, including:

* Commit hash
* Author
* Date
* Commit message
* Number of files changed
* Insertions
* Deletions

### `contributor_stats.csv`

Contains contributor activity statistics.

### `monthly_commits.csv`

Contains monthly development activity and average files changed.

### `frequently_changed_files.csv`

Contains files that have been modified most frequently in the repository history.

## Installation

Clone this project and create a Python virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

---

## Running the Project

First clone the Flask repository:

```bash
python src/clone_repo.py
```

Run repository inventory:

```bash
python src/repository_inventory.py
```

Generate the file-level dataset:

```bash
python src/file_analysis.py
```

Mine Git history:

```bash
python src/git_history.py
```

Analyze the generated data:

```bash
python src/analyze_data.py
```

Generate repository statistics:

```bash
python src/generate_stats.py
```

## Conclusion

This project demonstrates how an open-source software repository can be mined to obtain structured software engineering data.

The analysis combines source-code metrics with Git development history to provide information about the repository, its files, contributors, commits, and development activity. The resulting CSV datasets and JSON statistics can be used as input for subsequent software engineering data analysis and mining tasks.
